Я написал тесты для класса BooksCollector, который работает с книгами.

С помощью тестов я проверил:

1.Добавление книг с правильными и неправильными названиями.

2.Назначение жанра книге и получение её жанра.

3.Получение списка книг определённого жанра.

4.Получение полного списка книг с их жанрами.

5.Получение книг, подходящих для детей.

6.Добавление книг в избранное.

7.Удаление книг из избранного.

8.Получение списка избранных книг.

Чтобы запустить тесты  терминале нужно выполнить команду:

pytest -v tests.py

Все 12 тестов прошли успешно.
